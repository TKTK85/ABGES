# 连产性状算法（`clutch`）

## 定义

**连产（clutch）**：母鸡连续若干天每天产蛋，中间一旦停产一天即中断。一个连产序列的长度即"连产长度"。

- `ACL` = 该个体所有连产长度的**均值**
- `MCL` = 该个体所有连产长度的**最大值**
- `NCC` = 该个体的连产周期总数（每个连续产蛋段算1个周期）

## 原始记录纠错规则（v2）

| 同一个体同一天的记录条数 | 条件 | 处理 |
|---|---|---|
| `>= 3` | — | **整天丢弃**，记 change_log |
| `== 2` | 前一天**有**该鸡的记录 | 保留**第一条**，删除第二条 |
| `== 2` | 前一天**无**该鸡的记录 | 前向搜索最近空档平移；若目标日期被占用则标记双产日 |
| `== 1` | — | 直接保留 |

**双产日处理**：日期平移时目标日期已被占用 → 记为双产日；连产计数按 **1枚** 计入（生理上限）。`double_egg_days` 字段记录双产天数。

## 统计窗口

以个体**首次产蛋日到末次产蛋日**之间的连续日历日为窗口。窗口内无记录的日期视为停产，用于切分连产序列。

不使用全群统一窗口——个体开产日差异很大，统一窗口会把开产前的空白误算成停产。

## 回归锚点

测试用例中构造的已知答案：某个体产蛋序列为 `3天 + 停 + 2天 + 停 + 2天 + 停 + 3天`，则

```
连产长度序列 = [3, 2, 2, 3]
ACL = 2.5    MCL = 3
```

该断言固定在 `tests/unit/test_tools_smoke.py`。

# 累计产蛋数（`cumulative_egg_number`）

个体在统计窗口内的有效产蛋记录总数（经上述纠错后）。`validation: CEN >= 0 且 <= 400`。

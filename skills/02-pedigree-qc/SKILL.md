# SKILL 02 · Pedigree QC

系谱质控负责识别问题记录，并生成只包含合格系谱的分析用文件。执行规则以 `configs/qc/pedigree-qc.yaml` 和 `rules/ABGES_系谱逻辑检查规则.md` 为准。

## 一、核心原则

- 原始系谱只读。
- 对可定位到个体的系谱问题，直接剔除问题记录，不自动猜测或改写亲子关系。
- 若后代引用了被剔除或无系谱记录的亲本，后代及其受影响后代按依赖关系级联剔除，直至剩余系谱闭合、无环。
- 双亲为 `NA`/`0` 的有效个体是合法基础群成员，保留；未知亲本标记统一归一化，写引擎输入时转为 `0`。
- 近交系数高属于遗传状态，不是系谱记录错误，不得按 F 值剔除动物。
- 剔除后仅在任务准入条件仍满足时继续计算；否则阻断并报告。

## 二、检查与处理

1. 读取 `ID/Sire/Dam`，识别不到必需字段则阻断，不猜列。
2. 标准化字符串 ID，保留前导零；只执行明确配置的空白和缺失标记规范化。
3. 缺失 ID 行剔除；仅按 `ID/Sire/Dam` 三列完全相同去重；同一 ID 的 Sire 或 Dam 任一不同，则该 ID 全部记录剔除。其他可选字段差异不构成亲本关系冲突。
4. 自身作亲本、双亲指向同一非缺失 ID、无效亲本引用及任务明确启用的性别/日期逻辑冲突按记录级问题剔除。
5. 仅任务声明 `pedigree_generation_semantics: genetic_generation` 时执行显式亲子世代顺序硬校验；管理世代/批次不参与。晚世代未知亲本检查始终依据系谱推导的拓扑深度和 `late_founder_generation`，超过阈值仍有任一未知亲本时剔除该个体及后代。
6. 明确错误个体及其全部后代剔除，保留其父母和兄弟姐妹；成环时剔除环上个体并级联删除后代，保留无关分支。
7. 复查最终保留集合：ID 唯一、亲本均为未知或在保留集合中、无环且拓扑排序正确。
8. 对缺失可选列或未声明遗传世代的规则标记为 `not_applicable` 并说明原因。

规则适用及具体阈值由任务配置决定，覆盖猪、鸡、牛、羊，不把单一品系参数推广为通用生物学阈值。

## 三、必需输出

- 原始输入路径与校验信息；
- 逐条问题/剔除清单：原始行号、ID、Sire、Dam、规则编号、原因；
- 级联剔除关系；
- 每个删除个体的 ID、父母、行号、世代/批次/性别、触发规则和直接/级联原因；按规则及世代/批次/性别/父系家系统计剔除率；
- 原始规模、各规则剔除数、重复行去除数、级联剔除数、最终保留数；
- 合法基础群数量、单亲未知比例、父系/母系/双亲完整度及世代分布；
- 最终引擎系谱、拓扑和亲本引用校验结论；
- 被跳过的检查及原因。

## 四、任务准入

如果有未解决冲突、残余循环、无效亲本引用或拓扑错误，不得生成可用于评估的系谱文件。若剔除后数据规模、与表型/基因型匹配度或候选群覆盖率不满足任务配置，阻断运行。若满足准入要求，则使用清洁子集运行，并在状态与报告中披露系谱剔除情况。

## 五、流程接口

G2/G3 必须接收系谱 QC 的最终保留 ID 集、问题清单、剔除统计和 QC 状态。不得只传递 `warnings` 而丢失待处理冲突；不得在有记录级问题时仍把原始或未过滤系谱送入 HIBLUP。

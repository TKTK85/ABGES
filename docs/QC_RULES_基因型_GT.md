# ABGES 基因型质控规则（GT001–GT008）

> 本文件由 `scripts/render_qc_rules_md.py` 从 yaml 自动生成，请勿手改；
> 修改请编辑 `configs/qc/*.yaml` 后重跑该脚本。

权威源：`configs/qc/genotype-qc.yaml`（经 PLINK2）。

**QC 阈值**：mind=0.1（个体缺失率）→ geno=0.1（位点缺失率）→ maf=0.01 → hwe=1e-06；规模下限 SNP≥1000、样本≥50。执行顺序：先剔个体后剔位点。

| 规则 | 名称 | 强度 | 说明 | 动作 |
|------|------|------|------|------|
| **GT001** | 基因型文件完整性与非空校验 | 🔴 阻断 | 指定 --bfile 前缀时，.bed/.bim/.fam 三件套同时存在且可读；.bim 行数 > 0 且 .fam 行数 > 0 | 缺任一文件或文件为空即中止，报告缺失文件名、查找路径与实际行数 |
| **GT002** | 个体号与表型/系谱可对接 | 🔴 阻断 | .fam 第二列（IID）与表型文件个体号列的交集数量 > 0 | 交集为 0 时中止，输出两侧各 10 个样例个体号供人工比对（常见原因：FID/IID 顺序颠倒、前导零丢失） |
| **GT003** | 个体号唯一性 | 🔴 阻断 | .fam 的 IID 唯一 | 中止并列出重复个体号 |
| **GT004** | 位点标识与坐标规范 | ⚠️ 告警 | .bim 第二列 SNP 标识唯一、不为空且不为"."；第四列物理位置 > 0 | SNP 标识重复者保留首次出现，其余重命名为 <id>_dup<N>；标识缺失或占位者 按 chr:pos 重命名；物理位置为 0 或缺失者标记，需按染色体分块计算时剔除； 全部处理记录清单 |
| **GT005** | 非常染色体与单态位点处理 | ⚠️ 告警 | 统计性染色体（Z/W）、线粒体及未定位（chr 0）位点数量；每位点 MAF > 0（存在多态） | 非常染色体位点默认从基因组关系矩阵（GRM）构建中排除；单态位点由 maf 阈值 统一剔除；两类数量均单独写入统计 |
| **GT006** | 质控后规模门控 | 🔴 阻断 | 质控后保留位点数 ≥ min_snp_after_qc 且保留个体数 ≥ min_sample_after_qc | 不满足则判定 failed，明确告知阈值与实际值，不得继续构建 GRM |
| **GT007** | 高度相似样本核验 | ⚠️ 告警 | KING 亲缘系数 ≥ king_cutoff 的样本对 | 仅列出样本对清单交由人工判断，系统不自动剔除（家禽全同胞家系本身高度相关） |
| **GT008** | 性别编码一致性 | ⚠️ 告警 | .fam 第五列性别编码（1=公, 2=母, 0=未知）与表型文件性别列一致 | 冲突记录清单；GRM 构建不依赖性别，故不阻断 |

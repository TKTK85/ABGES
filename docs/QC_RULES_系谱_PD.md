# ABGES 系谱检查规则（PD001–PD015）

权威源：`configs/qc/pedigree-qc.yaml`。

三列 ID/Sire/Dam；缺失统一为 NA；最多向上追溯 5 代。

| 规则 | 名称 | 强度 | 说明 | 参数 |
|------|------|------|------|------|
| **PD001** | 系谱必备字段完整性（个体号/父号/母号） | 🔴 阻断 | 系谱须可解析出个体号、父号、母号三列（内部字段 ID/Sire/Dam）。 缺失任一即阻断：加性遗传相关矩阵（A 阵）构建与育种值求解依赖完整的亲本三元组。 | — |
| **PD002** | 个体号缺失与重复记录处理 | EXCLUDE_INVALID_RECORDS | 个体号缺失直接剔除；仅 ID/Sire/Dam 三列完全相同的重复行保留一条； 同一 ID 的父本号或母本号任一不一致时，剔除该 ID 的全部记录及其后代。 可选字段的差异不构成亲本关系冲突；每条被去除的重复行均进入剔除明细。 | keep=first |
| **PD003** | 标识符规范性（脏数据归一与翅号编码自洽） | NORMALIZE_AND_EXCLUDE_INVALID | 两阶段标识符治理。阶段一（清洗）：对个体号/父号/母号执行脏数据归一—— 去除前后空白、全角转半角、压缩内部多余空白属于无歧义规范化并记录 change_log； 规范化后发生 ID 冲突、或违反任务明示的编码约束时，剔除涉及记录及受影响后代； 不仅因 ID 样式不同就跨任务判错。 阶段二（校验）：同世代内翅号应唯一、编码规则应自洽（长度、字符集、前缀）； 提供独立翅号列则校验该列，否则退化校验个体号；无世代列时降级为全局编码 自洽检查并在报告中声明。编码自洽按"同世代内个体号模式签名一致性"判定。 | authoritative_source=系谱核查方案_WT.md#2.1 完整度（翅号唯一/编码格式自洽）；#2.2 常规错误（脏数据：前后空格/全角/大小写不一致） |
| **PD004** | 自交 / 自身作亲本（self-parenting） | EXCLUDE_RECORD_AND_DESCENDANTS | 个体号与父号或母号相同，剔除该个体及其全部后代；保留其父母和兄弟姐妹， 除非这些个体自身另有独立错误。 | — |
| **PD005** | 亲本存在性（无效引用剔除） | EXCLUDE_DEPENDENT_RECORDS | 非缺失父号/母号在系谱个体集中无对应记录时，剔除引用该亲本的子代记录， 并级联剔除受影响后代。不得把记录缺失的亲本自动认定为真实基础群。 | unknown_parent_policy=exclude_dependent_record |
| **PD006** | 亲本角色冲突与性别一致性 | EXCLUDE_CONFLICTING_RECORDS | 仅对已指定的猪、鸡、牛、羊任务，按物种繁殖角色及可靠性别字段检查。发现冲突时， 剔除冲突个体记录及受影响后代；不得猜测性别或改写亲本关系。无适用字段则注明跳过。 | — |
| **PD007** | 循环系谱检测（环检测） | EXCLUDE_CYCLE_AND_DESCENDANTS | 先输出完整环路径，再剔除环上个体并级联剔除其后代；保留其父母、兄弟姐妹及 无关分支。最终保留系谱必须无环。 | — |
| **PD008** | 世代/日期时序一致性 | EXCLUDE_INVALID_RECORDS | 只有任务明确声明 pedigree_generation_semantics=genetic_generation 时，才检查 遗传世代关系；亲本世代不早于子代时剔除个体及其后代。管理世代/批次不用于 该判断。出生日期按任务配置的范围与亲子顺序检查。 | — |
| **PD009** | 系谱拓扑排序与遗传世代分层 | 修改 | 输出前按有向图拓扑序重排，保证任一个体双亲出现在其之前（HIBLUP 对系谱 顺序有强制要求）。遗传世代 = max(父本世代, 母本世代) + 1，与按配种批次 划分的管理世代可能存在偏差，报告中须声明。 | — |
| **PD010** | 系谱完整度与晚世代未知亲本 | EXCLUDE_LATE_UNKNOWN_PARENT_RECORDS_AND_FLAG | 系谱拓扑深度晚于 late_founder_generation 时，任一未知亲本构成记录级错误； 剔除该个体及其后代。按系谱推导拓扑深度，不使用管理世代/批次。父母完整率 等其他群体指标按世代、批次、性别及父系家系统计报告。 | — |
| **PD011** | 幻影亲本组检测（phantom parent group） | ⚠️ 告警 | PBLUP 系谱中不应包含幻影亲本组个体。检出疑似幻影组时提醒先清理， 不自动删除。 | phantom_patterns=['^PG', '^phantom', '^幻影'] |
| **PD012** | 近交系数（Wright's F）核查 | 标记 | 基于系谱计算个体近交系数 F，标记 F ≥ inbreeding_flag_threshold 的个体， 并报告群体平均近交系数；阈值已对齐育种方案（WT 建议 0.0375），仅提示 不排除个体。 | inbreeding_flag_threshold=0.0375, compute_inbreeding=True, authoritative_source=系谱核查方案_WT.md#四、待确认参数（近交系数初设 0.0375，实际以育种方案为准） |
| **PD013** | 最小有效系谱规模 | 🔴 阻断 | 有效系谱个体数低于任务准入配置时阻断。该阈值服务于具体分析目的与数据规模， 不表示低于某固定规模就无法构建 A 矩阵。 | min_individuals=50 |
| **PD014** | 遗传世代定义与一致性 | EXCLUDE_CONFLICTING_RECORDS_AND_DESCENDANTS | 只有任务明确声明遗传世代字段时，才比较显式世代与拓扑亲子关系；亲本遗传世代 不早于子代时剔除问题个体及其所有后代。管理世代和批次不参与。世代定义、冲突 清单和影响范围写入报告。 | — |
| **PD015** | 血缘中断 / 链追溯（可查询性） | 标记 | 对最近 3–5 世代个体，分别沿父系链与母系链向上递归追溯，分类终点 （合法基础群 / 记录缺失 / 断链），汇总父系链完整率、母系链完整率、 平均链长、断链个体清单。合法双亲未知个体保留；有亲本 ID 但缺失亲本记录时， 按 PD005 剔除相关子代，不能补记为真实基础群。 | recent_generations=5, authoritative_source=系谱核查方案_WT.md#2.3 可查询性（最近 1-2 世代链追溯） |

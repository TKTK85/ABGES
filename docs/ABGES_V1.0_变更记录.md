# ABGES V1.0 变更记录

日期：2026-10-24
应用版本：V1.0（`VERSION=1.0.0`）

## 本次固化内容

- 建立源码发布快照、逐文件 SHA-256 清单和压缩包校验值；发布流程排除 `workspace/`、运行数据、虚拟环境、缓存与日志。
- 让显式固定效应清单成为 PBLUP、GBLUP、SSGBLUP 的实际入模合同；被过滤的自动候选告警改为说明“未进入本次模型”及处置动作。
- 按拟合因子诊断稀疏组、世代×批次连通性和固定效应设计矩阵秩；配置阈值集中在 `configs/qc/model-design.yaml`。
- 新增显式参考群配置。原始 EBV 不变，Excel 可另列参考群中心化 EBV；未指定参考群或样本量不足时不生成中心化值。
- 将世代均值默认作为描述统计；只有任务声明 `generation_semantics: genetic_generation` 才输出遗传趋势估计。
- 将 Top EBV 排名和选择比例统计标为假设情景；没有个体准确率与世代间隔时不计算 ΔG，不形成选种决策。
- 在三类模型的结果校验阶段加入可选独立验证，拒绝训练与验证 ID 重叠，报告预测能力、校准、偏差和 RMSE；预测能力不冒称遗传评估准确度。
- 统一可靠度口径：优先用 HIBLUP `PA_R2`，缺失时按 `1-PEV/VA` 推导；报告和 Excel 标出来源。
- 建立交付格式契约：Word、Excel、Markdown 与引擎结果为标准交付；JSON、checkpoint、pickle、日志和中间文件留在运行审计区。
- 系谱亲本角色 QC 按有性生殖群体的 sire/dam 角色通用执行，不以物种白名单决定是否运行。

## 使用约束

- 参考群的列和值由每个分析任务显式设置，不能默认把基础群或 Gen 0 当作遗传基准。
- 独立验证表型必须按拟合模型校正到目标尺度，且来自未参与拟合的个体；样本少于任务阈值时仅报告样本不足。
- V1.0 归档对应其 SHA-256 清单记录的工作源码状态。更新源码后需重建发布归档；引擎二进制通过 `tools/ENGINE_MANIFEST.json` 另行核验。

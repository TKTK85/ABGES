# 未知性状与固定效应自动处理方案（v1.1，待拍板）

> 背景：先生要求"衍生性状计算里要能处理未知性状加进来的情况——自动用英文母代替、并做好；固定效应等若出现未知项也要有处理策略"。
> 先生补充定调（17:57 后）：① 代号用英文**缩写**，如产蛋→CD；② 凡**中文表头**的固定效应，要**全部转换为英文**。
> 现状缺口：当前 `run_phenotype_qc` 只处理"任务显式请求的"性状/固定效应；**数据里多出来、既未被请求也未被 `trait-registry.yaml` 注册的列（尤其是中文表头），会被整列忽略**（不报错、不记录、不进模型）。这正是缺口。
> 设计原则（不可破）：① 不静默——任何中文/未知表头必须被发现、被转换、被记录；② 可追溯——原始中文名 → 英文代号映射必须落盘；③ 不发明——绝不为未知列编造衍生公式，只做"转英文名 + 分类 + 可选纳入"。

## 一、中文表头 → 英文代号 转换层（"英文母代替"的落地方式）

新增模块 `tools/Python/abges_unknown.py`，在现有 `header_map` 标准化**之前**插入一层"中文表头归一"，核心两函数：

- `chinese_to_code(header, cfg)` → 返回英文代号（含来源标记：registry / dictionary / pinyin / fallback）
- `normalize_headers(frame, cfg)` → 返回 `(rename_map, report)`，把中文/未知表头统一换成英文代号

**代号生成三级优先级（先生定调：用英文缩写，如产蛋→CD）**：

| 优先级 | 来源 | 示例 | 说明 |
|--------|------|------|------|
| 1 | `trait-registry.yaml` 的 `name_cn` 命中 | 产蛋数→`EN`、体重→`BW` | 已知点用规范码，保证与既有分析口径一致 |
| 2 | `configs/traits/header_translation.yaml` 人工维护的中文→英文缩写词典 | 批次→`Batch`、栋舍→`House` | 覆盖注册表外的常用中文表头 |
| 3 | **拼音首字母兜底**（pinyin initials） | 产蛋→`CD`、采食量→`CFL` | 先生明确示例"产蛋→CD"即此路；依赖轻量纯 Python 库 `pypinyin` |

- 三级均失败（非中文、非已知）→ 退化为"`UT_`/`UF_` + base26 字母"保底，确保必有代号。
- **落实"英文母代替"**：在 `working` 帧内 `frame.rename(columns=rename_map)`，下游（HIBLUP 命令、ANOVA、衍生计算）统一用英文代号引用，原始中文名仅存于映射表。
- 全部映射落盘在本次 `workspace/<task_id>/_runs/<run_id>/` 运行目录下（含 `original / code / source / role / action`）。

## 二、分类启发式（trait vs 固定效应 vs 排除）

转换完成后，对每个**原本未知**的列（现已有英文代号）按其**内容**判定角色：

| 指标 | 计算 | 判据 |
|------|------|------|
| `numeric_ratio` | 可转数值的非空值占比 | < `numeric_ratio_min`(默认0.5) → 排除（疑似文本/自由记录） |
| `n_unique` | 非空去重数 | ≤ `fixed_max_levels`(默认30) → 候选**固定效应**；> 该值且连续 → 候选**trait/协变量** |
| `id_ratio` | `n_unique / n_rows` | ≥ `id_uniqueness_ratio`(默认0.9) → 疑似个体号/重复标记 → **排除** |

- 低基数数值列（如 1–5 评分）默认判为固定效应；若实为连续性状，可在映射表复核后手动改 `role`。
- 全部阈值写入配置，不硬编码。

## 三、治理策略（默认行为 + 开关）

| 未知类型 | 默认行为 | 标注 | 可配开关 |
|----------|----------|------|----------|
| **中文表头固定效应** | **必须全部转英文代号**；转后按内容判为固定效应并纳入建模 | `AUTO_CN_FIXED_CONVERTED` | 不可关（先生明确要求） |
| 未知固定效应（已转英文） | 自动纳入建模（进 `effective_fixed_effects`） | `AUTO_UNKNOWN_FIXED` | `auto_include_unknown_fixed_effects`（关→挂起待确认） |
| 未知连续列（已转英文） | 注册为可用协变量（进 `effective_covariates`） | `AUTO_UNKNOWN_COVARIATE` | `auto_register_unknown_traits`（关→仅记录不纳入） |
| 疑似 ID / 文本 | 排除 | `EXCLUDED_LIKELY_ID` | 不可纳入 |

- **绝不自动编造衍生公式**：未知列一律按 raw 处理；衍生公式仍须来自 `derived-traits.yaml`，`get_derived_definition` 对未登记项继续抛 DT001。
- 所有中文/未知表头清单 + 映射表在 QC 报告 `unknown_columns` 段**显著列出**，并落盘运行目录。
- 诚实声明：分类是启发式，可能误判；报告须提示"未知/中文项已自动转英文并纳模，建议人工复核映射表后再采信结果"。

## 四、与各子系统的集成点

1. **`abges_phenotype.py::run_phenotype_qc`**（主集成点）
   - 在现有固定效应解析（281–435 行）**之前**插入 `normalize_headers` 调用；
   - 转英文后的未知固定效应/协变量加入 `effective_fixed_effects` / `effective_covariates`（受开关控制）；
   - 扩展 `PhenotypeQCResult` 增加 `unknown_columns` / `header_map_auto` 字段并在 `to_dict` 输出。
2. **`trait-registry.yaml`**：其 `name_cn` 直接作为优先级 1 字典源，无需改结构；新增 `configs/traits/header_translation.yaml` 承载优先级 2 的人工词典。
3. **`breed_insights.py`（ANOVA 固定效应 F 检验）**：本就遍历 `effective_fixed_effects` → 自动包含转英文后的 `CD`/`UF_*` 等未知固定效应，无需改逻辑（仅须确保发现阶段已写入 effective 列表）。
4. **`hiblup_tool.py` / runners**：`--dcovar/--qcovar` 读 `effective_fixed_effects`/`effective_covariates`，列已转英文代号，命令装配自然衔接。
5. **衍生性状 `abges_traits.py`**：`list_computable_traits` 按列存在判定；若公式 `required_traits` 含已转英文的列，则可用——但公式本身仍须注册，不触发"发明"。

## 六、待先生定夺的一点

**拼音兜底是否引入 `pypinyin` 依赖？**
- 方案 A（推荐）：优先级 3 用 `pypinyin` 自动取拼音首字母（产蛋→CD），能覆盖**任意**中文表头，零人工维护；代价是新增一个轻量纯 Python 依赖。

## 七、风险与诚实声明

- 重命名后原始中文名仅在映射表留存，必须保证映射表**每跑必落盘**且报告必列，否则不可追溯。
- 分类为启发式，1–5 评分等边界案例可能误判，须人工复核清单。
- 拼音兜底对多音字/生僻字可能取错首字母，重要性状仍建议进 `header_translation.yaml` 显式登记。
- 本方案为设计稿，**尚未在含中文未知列的真实数据上端到端验证**；落地后需用一份"混入中文未知表头"的实测数据走通 转换→QC→ANOVA→HIBLUP 全链。

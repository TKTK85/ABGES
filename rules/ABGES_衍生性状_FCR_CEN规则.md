# ABGES 衍生性状规则 · FCR/CEN

> 版本：v1.0 ｜ 更新：2026-08-11 ｜ 配套：衍生性状_通用合同与质控规则 / ACL/MCL 规则
> 覆盖：FCR（料重比）、CEN（截止年龄累计产蛋数）。

## 一、功能与启用

| 性状 | 含义 | CLI | 输入 | 输出 |
|------|------|-----|------|------|
| FCR | 料重比 | `--fcr` | FI、WG | 小数 |
| CEN | 截止年龄累计产蛋数 | `--cen` | ID、捡蛋日期、出生日期、目标年龄 | 整数 |

## 二、FCR 规则

### 2.1 定义
`FCR = FI / WG`（FI 采食量、WG 增重），须覆盖相同个体、相同时间窗、兼容单位；均克计则为无量纲比。FCR 越低单位增重耗料越少，解释须结合测定窗与选择方向。

### 2.2 有效性
| 情况 | 输出 |
|---|---|
| FI>0 且 WG>0 | 计算 FI/WG |
| 任一缺失 | FCR 缺失 |
| 任一为 0 | FCR 缺失并计错误 |
| 任一为负 | FCR 缺失并计错误 |
| 缺 FI/WG 列 | 警告，不生成 |

输入强制转数值，文本错误不得当 0。示例：`FI=3500g, WG=1400g → FCR=2.5`。

## 三、CEN 规则

### 3.1 目标合同
必须且只能提供一个正目标：`--target-day-age 300` 或 `--target-week-age 50`。两目标都不给 / 同时给 / 为 0 或负 → `E013`/ValueError 阻断。

### 3.2 出生日期优先级
1. 捡蛋记录自身出生日期；2. 缺失则回退表型 `出雏日期/BirthDate/hatch_date/birth_date`；3. 两处皆无 → 删该记录；4. 全部无来源 → 终止。

### 3.3 年龄
`day_age=(捡蛋日期-出生日期).days`；`week_age=ceil(day_age/7)`（等价 `day_age//7 + (day_age%7>0?1:0)`）。日龄 1→周龄 1；7→1；8→2。`day_age<0`（出生前产蛋）删除并警告。

### 3.4 过滤与计数
日龄模式留 `day_age<=target`；周龄模式留 `week_age<=target`；按 ID 计数。有有效来源但全在目标之后 → `CEN=0`；无有效来源 → 缺失不伪造 0。
⚠ 当前 CEN 计"有效记录数"，不复用 ACL 一日一枚校正，也不按 `ID+date` 去重；重复录入会重复计数。生产前须确认"一行=一枚有效蛋"，如需"按产蛋日计数 / 同日封顶 1 枚"须新增明确模式。

### 3.5 观察期不足
每 ID 算最大年龄：达目标 = 完整观察；小于目标 = 保留 CEN 并记 `data insufficient` 警告（日志逐只前 10，余汇总）。观察不足 CEN 不可与完整个体直接等价比较。

### 3.6 示例
出生 1/1，捡蛋日龄 `50,60,70,80,90,110`，目标日龄 100 → `CEN=5`（110 被排除）。

## 四、ID 匹配与输出

CEN：`match_rate = 表型 ∩ CEN ID数 / CEN ID数`；<10% 抛错停合并；达阈值按 `ID` 左连。FCR 在表型行内计算，不需额外合并。输出并入 `projects/<品系>/input/<品系>_pheno.txt`。

## 五、错误与阻断

| 问题 | 行为 |
|------|------|
| 捡蛋目录不存在(CEN) | FileNotFoundError 阻断 |
| 无出生日期来源 | ValueError 阻断 |
| 目标缺失 / 双给 / 非正 | E013/ValueError 阻断 |
| FI/WG 列缺失 | 警告，FCR 不生成 |
| FI/WG 非正 | FCR 缺失并计数量 |

## 六、定稿参数（依据 docs/ABGES_待确认参数总表.md）

- CEN 计数口径：**按"产蛋日数"封顶 1 枚/日**（更符合"产蛋持续性"语义）；"记录数"模式保留为可选 config 开关。
- 目标年龄默认：**未指定时使用品系标准观察期**（从 config 读取）。

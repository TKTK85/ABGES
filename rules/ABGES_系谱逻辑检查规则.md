# ABGES 系谱逻辑检查规则

> 规则版本：v2.1 ｜ 更新：2026-10-22 ｜ 适用范围：猪、鸡、牛、羊系谱评估任务

## 1. 总原则

1. 原始系谱只读；所有清理均在分析副本上完成。
2. 逐个体检查。发现可定位到个体的系谱问题时，**直接剔除该个体的系谱记录**，不自动猜测、改写或择取亲本关系。
3. 某记录被剔除后，若其后代仍引用该个体为父本或母本，则该后代的亲本链不再完整；按同一原则剔除受影响后代，迭代至剩余系谱不再引用已剔除或不存在的亲本。
4. 只将最终无未解决记录级问题的系谱写入引擎计算文件。若剔除后不满足任务准入条件，停止评估并报告原因。
5. 每条剔除必须留存原始行号、ID、Sire、Dam、世代、批次、性别、规则编号、原因和剔除/级联剔除关系；报告原始数、各规则剔除数、级联剔除数、分组剔除率及最终保留数。
6. 明确错误个体及其所有后代剔除，保留其父母和兄弟姐妹；只有父母另有独立错误时才剔除父母。

## 2. 未知亲本与基础群

- `NA`、`0`、空值、`N/A`、`NULL`、`未知`、`无`、`-` 等约定值统一识别为未知亲本；输出引擎文件时统一写为 `0`。
- 双亲未知的拓扑基础群个体保留；拓扑深度超过任务配置的 `late_founder_generation` 后，任一亲本未知则按问题记录剔除个体及后代。
- 晚期未知亲本检查只依据系谱推导的拓扑深度，不读取 `Gen`/批次；显式亲子世代顺序硬检查则仅在任务声明世代字段为遗传世代时启用。
- 非缺失亲本 ID 在系谱中缺档时，剔除引用该亲本的子代并级联；不得自动补造基础群。

## 3. 字段与标识符标准化

- 必需字段为 `ID`、`Sire`、`Dam`；支持配置的中英文表头别名。
- ID 全部按字符串读取，保留前导零；去除首尾空格、全角转半角、压缩多余空白。只对明确约定的缺失标记归一，不擅自改大小写、截断或拼接 ID。
- 缺失或空白 ID 的行直接剔除。
- 清理后 ID 冲突须进一步按重复规则处理；仅大小写不同但可能指向同一动物时，涉及的 ID 记录均列为冲突，不自动合并。
- 必需列无法识别或文件不可读时，任务阻断；不得猜列。

## 4. 记录级问题及处理

| 规则 | 判定 | 处理 |
|---|---|---|
| PD001 字段结构 | 缺少 ID/Sire/Dam 任一列 | 阻断，无法逐记录检查 |
| PD002 缺失/重复 ID | ID 缺失则剔除该行；`ID/Sire/Dam` 三列完全相同的重复行只保留一条；同一 ID 的 Sire 或 Dam 任一不一致，则剔除该 ID 的全部行 | 留存每行处置记录，不保留冲突 ID 的任一版本；其他可选字段差异不构成亲本冲突 |
| PD003 ID 规范性 | 去空白、全角规范化等无歧义清理；规范后发生 ID 冲突或违反任务明确编码约束 | 冲突/违规记录剔除；单纯格式差异不作为跨任务通用错误 |
| PD004 自身作亲本 | ID 等于 Sire 或 Dam | 剔除该个体记录，不把亲本改成未知 |
| PD005 亲本存在性 | 非缺失 Sire/Dam 不在系谱有效 ID 集中 | 剔除引用该亲本的个体记录及受影响后代；不自动补建基础群 |
| PD006 亲本角色/性别 | 违反任务配置的物种繁殖角色或与可靠性别资料冲突 | 剔除冲突记录及依赖后代；没有适用资料时注明跳过 |
| PD007 系谱成环 | 个体成为自身祖先 | 剔除环上个体及受影响后代；保留无关的无环分支 |
| PD008 世代/日期时序 | 仅当任务明确声明世代列是遗传世代，且亲本遗传世代不早于子代时才硬剔除；管理世代/批次不用于该判断。出生日期规则按配置启用 | 剔除问题个体及其所有后代；无字段或未声明遗传世代时注明跳过 |
| PD009 拓扑排序 | 父母排在子代之后 | 仅对有效系谱重排；不能通过排序修复错误亲子关系 |
| PD010 完整度/基础群结构 | 系谱拓扑深度超过 `late_founder_generation` 后仍有任一未知亲本，视为记录级问题；完整率等其余群体指标只作报告 | 剔除晚世代问题个体及其后代；报告按世代、批次、性别、父系家系的剔除率 |
| PD011 疑似幻影组 | ID 命中配置的幻影组模式 | 仅模式命中不自动判错；按任务定义核实后决定剔除 |
| PD012 近交系数 | F 偏高 | 作为遗传状态报告，不作为系谱错误，不剔除个体 |
| PD013 最小规模 | 清理后规模低于任务准入配置 | 阻断评估；阈值按任务配置，不宣称固定规模以下无法构建 A 阵 |
| PD014 世代判定 | 仅对明确声明为遗传世代的字段检查亲本—子代先后；管理世代不与拓扑世代强行比较 | 剔除冲突个体及其所有后代；报告方法和冲突数 |
| PD015 血缘链追溯 | 父系/母系链存在断点 | 按 PD005 处理缺失亲本引用，报告链完整度和级联剔除范围 |

“父母未知”本身不是错误；“父母相同但为未知标记”也不构成双亲相同错误。

## 5. 级联剔除、循环处理与保留集合

1. 先记录直接问题个体及其原始行号、ID、父母 ID、Gen/Batch/Sex、规则和原因。
2. 明确错误个体及其所有后代剔除；其父母、兄弟姐妹及未受影响支系保留，除非这些记录本身另有独立错误。
3. 非缺失亲本缺档或已剔除时，剔除引用它的子代并继续向后代级联，直至稳定。
4. 发现环时保存完整环路，只剔除环上个体并向后代级联；不因某个个体成环而删除其父母或无关支系。对最终集合复查无环、亲本引用闭合，再拓扑排序。
5. 仅最终合格集合可供 PBLUP/SSGBLUP 使用。

## 6. 不作个体剔除的群体指标

以下是群体或评估诊断，不单独作为剔除某个体的依据：已知父/母比例、双亲完整率、世代覆盖、系谱深度、创始群分布、家系规模、近交系数分布。它们须按世代/候选群体汇总；是否导致任务阻断由任务用途和配置决定。

高近交系数是动物遗传状态，不是系谱数据错误，**不得因 F 高而从遗传评估数据中剔除该个体**。应单独标记供育种决策使用。

## 7. 输出与准入

QC 至少输出：

- 原始系谱只读校验信息；
- 记录级问题清单及剔除原因；
- 规则级剔除数、重复去除数、级联剔除数；
- 每个删除个体的 ID/亲本/原始行号/原因，以及按遗传世代、批次、性别、父系家系的剔除数和剔除比例；
- 合法基础群数、单亲未知数、缺失亲本引用数；
- 各世代父系/母系/双亲完整率及系谱深度；
- 最终保留系谱、拓扑顺序检查结果和与分析群体的匹配情况；
- 剔除前后统计及可复现的规则配置版本。

最终剩余系谱为空、关键亲本关系仍有未决冲突、存在环，或不满足任务的最小数据/匹配条件时，阻断评估。只要仍有合格记录且任务准入通过，就使用合格子集计算，并在结果状态与报告中披露剔除情况。

## 8. 可配置项

物种繁殖角色、世代定义、出生日期合法范围、亲子年龄区间、ID 格式、最小分析规模和系谱匹配阈值均按物种/品系/任务配置。不得把某一个品系的数值阈值当成全项目默认生物学定律。

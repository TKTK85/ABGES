# ABGES 衍生性状规则 · ACL/MCL（连产）

> 版本：v1.1 ｜ 更新：2026-10-16 ｜ 配套：衍生性状_通用合同与质控规则 / FCR/CEN 规则
> 覆盖：连产类衍生性状 ACL（平均连产长度）、MCL（最大连产长度）、NCC（连产周期数）。

## 一、功能与启用

| 性状 | 含义 | CLI | 输入 | 输出 |
|------|------|-----|------|------|
| ACL | 平均连产长度 | `--acl` | ID、捡蛋日期 | 小数 4 位 |
| MCL | 最大连产长度 | `--acl` | ID、捡蛋日期 | 整数 |
| NCC | 连产周期数 | `--acl` | ID、捡蛋日期 | 整数 |

`--acl` 同时生成 ACL、MCL、NCC（共享同一套连产段）。

## 二、共用执行合同

1. 用户须明确启用性状；2. 输入先表头与 ID 标准化；3. 结果只按 `ID` 合并，禁按行号；4. 不改原始数据；5. 记录输入目录 / 文件数 / 有效数 / 异常数 / 匹配率 / 参数；6. 捡蛋与表型 ID 重叠率 <10% 终止；7. 衍生性状在 Step7 复用同一异常值与标准化 PH007；8. 单性状保留原始尺度，多性状强制 z-score；9. 无法计算输出缺失 / 空，禁伪造 0（仅业务明确允许才输出 0）。

## 三、捡蛋记录输入

目录依次查找 `data/<品系>/egg_records/`、`data/<品系>/计算连产产蛋数据/`，或 `--egg-dir` 指定；自动汇总 `*.csv` 按名排序。
ID 候选：`ID/个体ID/个体编号/个体号`；日期候选：`date/采集日期/捡蛋日期/日期`。先列名匹配，再用前 10 非空值判日期 / 数字特征；仍失败则末列作 ID、倒数第二列作日期并写警告。
编码优先自动检测，失败依次：`utf-8-sig/gbk/gb2312/gb18030/big5/latin1/cp1252`。支持 `2023-04-30`、`2023/04/30`、`2023年4月30日`、`20230430`、`2023.04.30`。无法解析 / 空 ID / 空日期删除；ID 转字符串去首尾空格。

## 四、连产规则

### 4.1 定义
连产段 = 同个体连续每天有产蛋的时间段，中间任一天无蛋即结束。
`ACL = Σ段长 / 段数`（保留 4 位小数）；`MCL = max(段长)`（整数天）。

### 4.2 一日记录校正（v2）
按 `ID+date` 计当天记录数：

| 当天记录数 | 条件 | 处理 |
|---:|---|---|
| 1 | — | 直接保留 |
| 2 | 前一天**有**该鸡的记录 | 保留**第一条**，删除第二条 |
| 2 | 前一天**无**该鸡的记录 | 前向搜索最近空档（最多7天）平移；若目标日期被占用则标记双产日 |
| ≥3 | — | 整天丢弃，严重异常并警告 |

**双产日处理**：日期平移时目标日期已被占用 → 记为双产日；连产计数按 **1枚** 计入（生理上限）。`double_egg_days` 字段记录双产天数。

### 4.3 算法
每 ID：日期升序 → 生成完整日历 → 有记录记 1、无记 0 → 连续 1 分段 → 首段 / 末段 / 长度 1 段全纳入 → 算 ACL/MCL。

### 4.4 示例
日期 `1/1,1/2,1/3,1/5,1/8,1/9` → 段长 `[3,1,2]`：`ACL=(3+1+2)/3=2.0000`，`MCL=3`。

### 4.5 空结果
无 CSV / 全不可读 → 空 `ID,ACL,MCL,NCC`；校正后无有效日 → 空；某个体无有效段 → 缺失不写 0。

## 五、ID 匹配与输出

`match_rate = 表型 ∩ clutch ID数 / clutch ID数`；<10% 抛错停合并；达阈值则按 `ID` 左连表型，无结果个体保持缺失，不新增无表型个体。合并后再次强制数值化。
输出并入 `projects/<品系>/input/<品系>_pheno.txt`（ACL/MCL/NCC/double_egg_days）。不得把空结果当 0，日志有错不得报完成。

## 六、错误与阻断

| 问题 | 行为 |
|------|------|
| 捡蛋目录不存在 | 警告，ACL/MCL/NCC 不生成 |
| ID 匹配率 <10% | ValueError 阻断合并 |
| 日期无法解析 | 删除；全无效则空结果 |
| 一天 ≥3 条 | 该日删除并警告 |
| 双产日（日期冲突） | 记录到 double_egg_days，连产计数按1枚计入 |

## 七、定稿参数（依据 docs/ABGES_待确认参数总表.md）

- 跨日双产校正：**以前日是否有产蛋记录区分，不结合产蛋时段**（简单稳健，时段数据通常不全）。

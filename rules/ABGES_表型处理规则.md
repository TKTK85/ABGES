# ABGES 表型处理规则

> 版本：v1.0 ｜ 更新：2026-08-11 ｜ 阶段：Phase 1

## 1. 读取

支持 Excel/CSV/TXT/TSV，编码自动尝试 UTF-8/GBK/GB2312。所有 ID 按字符串读入，保护前导零，禁止科学计数法和 `.0` 污染。输入发现规则见 `ABGES_运行规则.md` §3。

---

## 2. 表头标准化

通过 `BUILTIN_HEADER_MAP` + config `header_map` 映射（大小写不敏感）：

| 内部名 | 常见原始名称 |
|--------|------------|
| ID | 翅号、个体号、个体编号、ID |
| Gen / Batch / Sex | 世代、代次、批次、性别 |
| Age / BirthWt / AFE | 日龄、初生重、开产日龄 |
| BW / EW / EN / ER / FI / WG | 体重、蛋重、产蛋数、产蛋率、采食量、增重 |
| ACL / MCL / FCR / CEN | 平均连产、最大连产、料重比、累计产蛋 |
| Sire / Dam | 父本、母本 |

未识别列保留；同名列消歧。清洗前必须 schema 校验：缺 ID 或请求性状 → E003/E004，重复列 → E005。

---

## 3. 类型、空值、ID

- 请求性状中的非缺失文本不以 E012 静默转 NaN，阻断并报告字段、行号、示例值。
- 缺失标记：`-`、`--`、`N/A`、`NA`、`.`、`无`、`缺`、`null`、`#N/A`。
- 固定效应缺失不前向填充。ID 去首尾空格 → 字符串；空/NA/NONE/NULL → E003。Sire/Dam 的 `0`/空 → `NA`。

---

## 4. 重复记录

有 `Gen` 列按 `ID+Gen` 去重，否则按 `ID`。保留首条，schema 阻断重复键（E006）。

---

## 5. 性别标准化

`1/M/male` → 公；`2/F/female` → 母；空 → NA；未识别 → NA + 警告。不前向填充。

---

## 6. 异常值与标准化

按 `Gen×Batch` 分组（`threshold=3`，`min_group_size=5`）：组样本不足跳过该组/性状；均值 ± `threshold×SD` 识别异常值并记录；标准差为零跳过。

模式合同：single 默认不标准化（`--force-standardize` 可开启）；multi 强制组内 z-score（`--no-standardize` 被 E013 阻断）。`Batch/Gen` 均不存在时回退全体样本（`scope=all`）。固定效应仅一水平 → E022，命令层自动省略。

---

## 7. 输出审计

保留：清洗后 HIBLUP 表型文件、标准化统计量 JSON、被剔除记录及原因、输入+配置哈希、运行日志（行数、错误码）。生产运行必须先 dry-run + schema 校验。

## 定稿参数（依据 docs/ABGES_待确认参数总表.md）

- 异常值阈值 `threshold=3`、`min_group_size=5`：**全局统一 3σ + 分组样本≥5，不放宽到单品系/世代特例**（config 可覆盖）。
- 固定效应缺失策略：**维持不前向填充**；如确需回退值，须由 config 显式配置并记入审计，不默认开启。

# ABGES 系谱处理规则

> 规则版本：v2.1 ｜ 更新：2026-10-22 ｜ 适用物种：猪、鸡、牛、羊

本文件规定系谱数据从读取到引擎输入的处理流程。记录级判断依据统一见 [ABGES_系谱逻辑检查规则.md](ABGES_系谱逻辑检查规则.md)。

## 1. 输入与来源

当前评估入口读取任务明确指定的系谱文件，不自动合并独立系谱与表型内嵌的亲本列。若同一分析存在多个系谱来源，应先完成来源核验并明确唯一输入文件；跨来源自动比对/合并尚未接入执行代码。

系谱输入原件只读。列识别、格式转换、剔除和排序都在运行副本中完成。

## 2. 标准化

1. 映射配置的表头别名到 `ID`、`Sire`、`Dam`。
2. 三列按字符串读取并保留 ID 前导零；执行规则文件规定的空白、全角字符和缺失标记规范化。
3. 未知亲本标记统一转换为内部 `NA`。`NA`、`0`、空值等标记按配置识别。
4. 不依据猜测改写、截断、拼接或纠正 ID 和亲本关系。

## 3. QC 与剔除流程

```text
读取并校验原件
  ↓
记录原始规模与校验信息
  ↓
标准化 ID 与未知亲本标记
  ↓
按 ID/Sire/Dam 三列识别重复或冲突
  ↓
剔除直接问题个体并级联删除其后代
  ↓
成环时只删环上个体及其后代，保留父母和无关支系
  ↓
最终图复查、统计剔除影响、拓扑排序
  ↓
生成引擎系谱与含删除明细的报告
```

`ID/Sire/Dam` 三列完全相同的重复行只保留一条；同一 ID 的 Sire 或 Dam 任一不一致，则该 ID 全部记录删除。仅其他可选字段不同不构成亲本关系冲突。明确错误个体及其所有后代删除，保留父母和兄弟姐妹，除非它们自身另有独立错误。

双亲均为未知的拓扑基础群个体保留；超过 `late_founder_generation` 所设拓扑深度后，任一亲本未知则删除个体及后代。该检查始终依据系谱亲缘关系推导的拓扑深度，不读取 `Gen`、管理世代或批次。亲子世代先后硬检查则仅在任务声明 `pedigree_generation_semantics: genetic_generation` 时启用。物种繁殖角色检查仅在任务声明猪、鸡、牛或羊时启用。

## 4. 统计与报告

分别记录：

- 原始读入行数、规范化后 ID 数；
- 按规则编号剔除数、重复记录去除数、级联剔除数；
- 合法双亲未知基础群数、单亲未知数；
- QC 后最终保留数、与表型/基因型/候选群体的 ID 匹配数；
- 按世代/群体的父系、母系、双亲完整率及可追溯深度；
- 所有被跳过的检查及原因；
- 每条删除记录的 ID、父母、行号、Gen/Batch/Sex、规则、直接/级联原因；以及按规则、世代、批次、性别、父系家系的剔除数和比例。

每个剔除项保留原始行号、原始值、规则 ID、原因和父代/子代依赖关系。报告须区分“因系谱质量剔除”和“因缺失表型未参与性状估计”的个体。

近交系数和家系信息是遗传评估/育种决策指标；高 F 不构成系谱错误，不因高 F 自动剔除个体。

## 5. 引擎输入

- 引擎输入只包含通过 QC 的最终系谱记录，字段为 `ID, Sire, Dam`。
- 未知亲本按引擎接口规范输出为 `0`；内部仍保留统一的缺失值语义。
- 输出前复查 ID 唯一、亲本引用有效或为未知值、无环、父母先于子代。
- 最终系谱为空、拓扑检查未通过或任务规定的准入条件不满足时，不调用遗传评估引擎。
- 对 QC 剔除比例及最终保留规模的阈值由任务配置确定；报告记录规则版本和实际阈值。

## 6. 原始数据保护

不得覆盖原始系谱文件。标准化系谱、剔除清单、变更日志、统计和引擎输入写入本次运行目录，并使用运行 ID 与输入校验信息关联。

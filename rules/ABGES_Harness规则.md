# ABGES Harness 质量检查规则

> 版本：v1.0 ｜ 更新：2026-08-11
> 定位：独立于所有执行 Agent 的质量检查层，全程门禁，不归属任何业务 Agent。

## 一、职责与产物

Harness 在四阶段（P0 理解 / P1 数据 / P2 分析 / P3 报告）之间插入 6 维门禁，维护 `checkpoint.json`（阶段、状态、产物清单、阻断项）。任一高严重度项未通过即阻断，不得进入下一阶段。

## 二、六维检查

### 2.1 输入校验
| 检查项 | 判定 | 级别 |
|--------|------|------|
| 输入文件存在 | 路径不存在 | 🔴 高 |
| 必填列齐全 | 缺 ID / 性状 / 系谱列 | 🔴 高 |
| 编码可解析 | 自动 + 候选编码均失败 | 🔴 高 |
| 列名无重复 | 同名列 | 🔴 高 |

### 2.2 过程监控
| 检查项 | 判定 | 级别 |
|--------|------|------|
| 外部调用退出码 | HIBLUP / PLINK 非 0 | 🔴 高 |
| 日志无致命错误 | 出现 E0xx 未处理 | 🔴 高 |
| 长任务 checkpoint | >5min 无 checkpoint 写入 | 🟡 中 |

### 2.3 产物完整性
| 检查项 | 判定 | 级别 |
|--------|------|------|
| 预期产物存在 | 缺 .vars / .rand / .beta 等 | 🔴 高 |
| 产物非空 | 文件 0 字节 | 🔴 高 |
| 行数合理 | EBV 行数 ≠ 个体数 | 🟡 中 |

### 2.4 跨阶段一致性
| 检查项 | 判定 | 级别 |
|--------|------|------|
| ID 集合一致 | 上下游 ID 差集 ≠ ∅ | 🔴 高 |
| 个体数一致 | 表型 / 系谱 / EBV 计数不符 | 🔴 高 |
| 参数一致 | 调用的 method / fixed_effects 与配置不符 | 🟡 中 |

### 2.5 外部工具状态
| 检查项 | 判定 | 级别 |
|--------|------|------|
| HIBLUP 版本 | <1.7.0 | 🔴 高 |
| PLINK 可用 | GBLUP / SSGBLUP 缺 PLINK | 🔴 高 |
| 收敛标志 | .log 未收敛 | 🟡 中 |

### 2.6 最终交付门禁
| 检查项 | 判定 | 级别 |
|--------|------|------|
| 报告四部分齐全 | 缺失任一部分 | 🔴 高 |
| 无伪造完成 | 日志有错却报成功 | 🔴 高 |
| 退出码 ≠ 成功代名词 | 仅看退出码 0 | 🔴 高 |

## 三、checkpoint.json 结构

```json
{ "phase":"P1", "status":"pass|block", "artifacts":["..."], "blockers":["E0xx:..."], "ts":"ISO8601" }
```

## 四、执行纪律

1. 原始数据永不修改；2. 退出码 0 ≠ 成功，必须核验产物；3. 失败不得报告为成功；4. 交付强制 `✓完成 / ✗缺失 / ⚠风险`；5. 高严重度阻断须显式列出并暂停。

## 五、定稿参数（依据 docs/ABGES_待确认参数总表.md）

- 跨阶段 ID 差集容忍：**0 容忍，无豁免名单**；任何差集必须书面解释后方可继续。
- 产物行数偏差容差：**允许偏差 = 无表型/基础群个体数**；EBV 行数少于个体数属正常缺失，超出即告警。
- 未收敛处置：**先 EM 诊断 + 提合理初值**；仍不收敛 → 报告 partial 并标风险，**不静默、不伪装成功**（对齐 SKILL 安全规则）。

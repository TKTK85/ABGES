# ABGES 报告生成模板规则

> 版本：v1.0 ｜ 更新：2026-08-11 ｜ 阶段：Phase 3

## 1. 目录结构

```
projects/<品系>/reports/
├── 00_产物检查点/          # 完整性校验
├── 01_表型质控报告/        # 表型 QC
├── 02_系谱质控报告/        # 系谱 QC
├── 03_遗传评估报告/        # HIBLUP 结果 + EBV
├── 04_遗传进展图/          # EBV 按世代（多世代适用）
├── 05_基因型质控报告/      # 基因型 QC（GBLUP/SSGBLUP）
├── 06_数据处理前后对比图/  # 清洗前后对比
├── 07_遗传力与EBV分布图/   # 遗传力柱状图 + EBV 分布
└── 08_遗传评估报告_Word/   # Word 综合报告
```

---

## 2. 报告内容

| 目录 | 产物 |
|------|------|
| 01 表型质控 | 描述性统计 CSV（N/均值/SD/min/max/中位数/Q1/Q3，按 Overall/Gen/Batch 分组）+ 清洗日志 Excel + 表型进展图 PNG |
| 02 系谱质控 | 问题清单 Excel（行号/ID/Sire/Dam/类型/级别/说明/建议）+ 统计汇总 |
| 03 遗传评估 | 报告 TXT+Excel（方差组分/h²/固定效应/EBV Top10）+ 全量 EBV CSV（合并 `.rand` 各性状 + LEFT JOIN 表型，含无表型祖先，utf-8-sig）。Top10 是展示设计非数据缺失。 |
| 04 遗传进展 | EBV 按世代箱线图 PNG。仅多世代适用，单世代自动跳过。 |
| 05 基因型 QC | Excel：描述统计 + 过滤明细 + HWE/杂合度标记 + 16 条标准对照 |
| 07 分布图 | 遗传力柱状图 + 各性状 EBV 分布直方图/密度图 |
| 08 Word | 整合全部结果的正式报告（方法学/表格/图表引用） |

---

## 3. 检查点

`utils/checkpoint.py` 自动校验：`file`（文件存在且非空）、`dir_nonempty`（目录非空）、`glob`（匹配文件数≥min）、`viz_dirs`（子目录数≥min 且每个≥3 PNG）。

| 阶段 | 检查项 |
|------|--------|
| data | 表型/系谱 input 文件、表型质控目录、描述统计 CSV、清洗日志、系谱 QC、对比图(≥3-4 PNG)、表型进展图 |
| analysis | .vars、遗传评估 TXT/Excel、全量 EBV CSV、遗传进展图（单世代跳过）、Word 报告、分布图 |
| 基因组方法 | 仅查基因型 QC + .vars + 报告 + 全量 EBV，不要求进展图/Word/07 |

检查点报告写入 `00_产物检查点/`，含通过/缺失/总计，缺失项打印 `[缺失] 名称 — 详情`。新增/调整产物必须同步更新 `checkpoint.py`，不为通过而放宽匹配。

---

## 4. 命名

文件名含品系+性状+时间戳（`<品系>_<性状>_<时间戳>_report.txt`）。禁用"final/v2/最新版"。CSV 用 utf-8-sig，TXT 用 UTF-8。

## 定稿参数（依据 docs/ABGES_待确认参数总表.md）

- 检查点产物清单：**必须覆盖全部品系 × 方法（PBLUP/GBLUP/SSGBLUP）组合**；新增组合须同步扩展 `checkpoint.py`。
- Word 报告字段：**支持品系自定义章节与指标**，默认章节含方法学/数据质控/遗传参数/EBV Top/图表；具体字段以 config 定义为准（总表 #35）。
